FitCuy

Exercise/home‑workout demo app built during Dumbways Offline Week 1.

✨ Overview
FitCuy (a.k.a FitLog) is a simple fitness logging app example focused on home workouts. The repo contains a frontend (Next.js) and a backend folder (Express.js) and connect with (Supabase)

root/
├─ fitlog/ # Frontend: Next.js + Tailwind CSS + (Supabase client)
└─ fitlog-backend/ # Backend service (Node/Express or similar)

🧰 Tech Stack

Frontend: Next.js, React, Tailwind CSS, TypeScript, with many frontend library
Auth/DB (client): Supabase (URL + anon key)

Backend: Express with Node.js runtime
